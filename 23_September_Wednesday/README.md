# Day 3 — Wednesday 23 September: Sample Components

## Topic

Model neutron and X-ray samples for diffraction, imaging, small-angle scattering, absorption, and fluorescence experiments.

## Content

The three folders contain the day's material:

- [`06_morning_samples_1`](06_morning_samples_1): diffraction and imaging sample exercises, including PowderN, battery imaging, and a SANS inverse-problem example.
- [`07_afternoon_samples_2`](07_afternoon_samples_2): McXtrace absorption and fluorescence spectroscopy examples based on the ROCK and LUCIA beamlines.
- [`inputs`](inputs): supporting source slides and reference notes about McStas and McXtrace sample components.

The shared lecture slides are available as [`McStas_McXtrace_Sample_Components.pptx`](McStas_McXtrace_Sample_Components.pptx) and [`McStas_McXtrace_Sample_Components.pdf`](McStas_McXtrace_Sample_Components.pdf).
