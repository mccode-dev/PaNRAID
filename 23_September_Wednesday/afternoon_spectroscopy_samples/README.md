# Day 3 — Wednesday 23 September (Afternoon): Spectroscopy Samples

## Topic

Modelling of samples for spectroscopy experiments, with a focus on X-ray Absorption Spectroscopy (XAS).

## Content

- Principles of XAS and related spectroscopic techniques
- Simulation of radiation–matter interactions (neutrons/X-rays) for spectroscopic modelling
- Generating annotated, realistic spectroscopic datasets for AI model training
- Linking multi-scale simulations (DFT, MD) to macroscopic spectral signatures

## Learning Outcomes

By the end of this session, participants should be able to:

- Set up a spectroscopy sample model and configure an appropriate virtual experiment
- Produce synthetic XAS or inelastic scattering spectra with realistic noise and artefacts
- Understand how to label simulated spectroscopic data for use in supervised learning pipelines
