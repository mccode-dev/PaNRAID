# Day 3 — Wednesday 23 September (Afternoon): Samples - Spectroscopy/absorption (McXtrace)

*PaNRAID School, Day 3 afternoon — includes a lecture and practicals*

## Topic

Modelling of samples for spectroscopy experiments, with a focus on X-ray Absorption and Fluorescence Spectroscopy (XAS/XRF).

In this session we propose to use some spectroscopy sample models:

- Absorption (using `Filter`, `Absorption_sample`, `Abs_objects`, and `Fluorescence` components)
- Fluorescence, together with absorption, Compton and Rayleigh scattering

## Content

- Principles of XAS and related spectroscopic techniques
- Generating annotated, realistic spectroscopic datasets for AI model training

## Learning Outcomes

By the end of this session, participants should be able to:

- Set up a spectroscopy sample model and configure an appropriate virtual experiment
- Produce synthetic XAS and fluorescence spectra with realistic noise and artefacts
- Understand how to label simulated spectroscopic data for use in supervised learning pipelines
