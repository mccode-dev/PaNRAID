# Day 2 — Tuesday 22 September (Afternoon): Optics

## Topic

Simulation of optical components used in experimental setups.

## Content

- Overview of optical elements: lenses, mirrors, monochromators, collimators, and guides
- Role of optics in signal formation and beam conditioning
- Modelling optical components in McStas/McXtrace to faithfully reproduce experimental artefacts
- Practical exercises: assembling an optical path in a virtual beamline

## Learning Outcomes

By the end of this session, participants should be able to:

- Identify and select appropriate optical components for a given experimental configuration
- Simulate a beamline segment including optical elements
- Understand how optical imperfections and misalignments manifest as artefacts in recorded data
