# Facilitator Notes — Sources & Monitors

Internal notes for whoever is running [`Exercises_Sources_and_Monitors.md`](./Exercises_Sources_and_Monitors.md); not intended for participants.

- Exercises 1–4 are the core material for absolute beginners and should comfortably fit a ~2 hour hands-on block; 5 is a natural extension once time allows; 6–7 are stretch goals for fast finishers or a follow-up session.
- All code snippets in the exercise sheet are self-contained and were checked against the parameter names used in the accompanying lecture slides (`McStas_McXtrace_Sources_and_Monitors.pptx`) and against the `templateDIFF` example instrument already in this repository (`instruments/mcstas/templateDIFF/templateDIFF.instr`).
- A [`hints/`](./hints/) folder with ready-made starter `.instr` files exists, covering Exercise 2 only (both codes). Exercises 5 and 7 are not covered by a starter file and are still typed from scratch.
- Every exercise now follows a fixed nine-part template (Learning objectives / Physical background / Starting instrument / Task / Expected output / Questions for interpretation / Optional extension / Data-export step / Checkpoint-solution), matched across the Optics and PowderN sheets — this is deliberate, so participants build a predictable habit of reading an exercise the same way every time.
- Exercise 4 was substantially expanded from the original "statistics" exercise into "Statistics and normalisation: what actually changed?" — it now explicitly drills the four-way distinction (physical change / Monte Carlo noise / binning / normalisation convention) that a reviewer flagged as essential for anyone who will later use this kind of simulated data for AI training. Worth allowing extra time for this one specifically; it's the pedagogical anchor for the whole sheet.
- A new "Recording a simulation contract" section (before Exercise 1) introduces the six-fact contract (parameters, seed, ncount, monitor settings, output files, software version) that every exercise's Data-export step now asks for. This is intentionally lightweight (a text file is enough) — the point is habit-forming, not tooling, ahead of the school-wide [`Data_Generation_Pipeline.md`](../../../Data_Generation_Pipeline.md) document, which formalises the same six facts into a per-sample metadata schema for Day 4.
- Facilitator judgement call: if the group is short on time, Exercise 4's normalisation sub-tasks (steps 2 and 4) are the most skippable without breaking the flow to Exercise 5 — but they're also the most directly relevant to the AI framing, so skip them last, not first.
