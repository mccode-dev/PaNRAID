Internal notes for whoever is running [`Exercises_Sources_and_Monitors.md`](./Exercises_Sources_and_Monitors.md); not intended for participants.

- All code snippets in the exercise sheet are self-contained and were checked against the parameter names used in the accompanying lecture slides (`McStas_McXtrace_Sources_and_Monitors.pptx`) and against the `templateDIFF` example instrument already in this repository (`instruments/mcstas/templateDIFF/templateDIFF.instr`).

Exercises 5 and 7 are not covered by a starter file and are still typed from scratch — turning those into starters too (with a few `???` gaps for participants to fill in) remains a reasonable next step if useful.
