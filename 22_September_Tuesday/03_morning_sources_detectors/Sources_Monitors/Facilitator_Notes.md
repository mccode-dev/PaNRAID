# Facilitator Notes — Sources & Monitors

Internal notes for whoever is running [`Exercises_Sources_and_Monitors.md`](./Exercises_Sources_and_Monitors.md); not intended for participants.

- **Tuesday-morning merge.** This session used to be a full morning (09:00–12:00) on its own; it now shares that same morning slot with Optics. The exercise sheet was cut from seven exercises down to three core ones (Exercise 1: doc lookup + first beamline, merging the old warm-up and Exercise 2; Exercise 2: shaping the source, the old Exercise 3; Exercise 3: statistics and normalisation, the old Exercise 4, trimmed from five sub-tasks to two). The old Exercises 5–7 (`Monitor_nD`, realistic source spectra, MCPL coupling) are now one paragraph each under "Further material, if time allows" at the end of the sheet, rather than full exercises — point fast finishers or the self-directed at that section rather than trying to run it live.
- **Deliberate template departure.** Because of the time pressure, this sheet (and the Optics sheet) now uses a leaner Goal/Task/Checkpoints structure instead of the nine-part template (Learning objectives / Physical background / Starting instrument / Task / Expected output / Questions for interpretation / Optional extension / Data-export step / Checkpoint-solution) still used by the PowderN and Batteries sheets later in the week. This is a deliberate, flagged inconsistency driven by the schedule change, not a silent drift from the "same template everywhere" principle — worth mentioning to participants if anyone asks why Tuesday's sheets look different from Wednesday's.
- All code snippets are self-contained and were checked against the parameter names used in the accompanying lecture slides (`McStas_McXtrace_Sources_and_Monitors.pptx`) and against the `templateDIFF` example instrument already in this repository (`instruments/mcstas/templateDIFF/templateDIFF.instr`).
- A [`hints/`](./hints/) folder with ready-made starter `.instr` files exists, covering the build-an-instrument step of Exercise 1 only (`ex2_mcstas_starter.instr`/`ex2_mcxtrace_starter.instr` — filenames unchanged from the old Exercise 2 numbering). Exercises 2 and 3 are done by editing that same instrument.
- Exercise 3 (formerly Exercise 4, "Statistics and normalisation: what actually changed?") is still the pedagogical anchor of the sheet — a reviewer flagged the physical-change/Monte-Carlo-noise/binning/normalisation four-way distinction as essential for anyone who will later use this kind of simulated data for AI training. It's been trimmed to two sub-tasks (noise, normalisation) rather than the original four; binning and pulsing are now "if time allows" notes at the end of that exercise instead of numbered sub-tasks — if the group has any spare time at all, binning is the one worth reinstating first, since it's the sub-task most often confused with normalisation.
- The "Recording a simulation contract" section (before Exercise 1) is unchanged: the six-fact contract (parameters, seed, ncount, monitor settings, output files, software version) that every exercise's Task still ends by asking for. This is intentionally lightweight (a text file is enough) — the point is habit-forming, not tooling, ahead of the school-wide [`Data_Generation_Pipeline.md`](../../../Data_Generation_Pipeline.md) document, which formalises the same six facts into a per-sample metadata schema for Day 4.
- Facilitator judgement call under the new, tighter timing: if the room is short on time even for the three core exercises, Exercise 2 (shaping the source) is the most skippable without breaking the flow from Exercise 1 to Exercise 3 — Exercise 3's normalisation sub-task is the one to protect, since it's the direct AI-framing payoff for the whole sheet.
