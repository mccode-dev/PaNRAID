# Day 5 — Friday 25 September (Full Day): AI Applications — Inference

## Topic

Applying trained AI models to perform inference on real and simulated experimental data.

## Content

- Deploying trained models on held-out simulated data and real experimental measurements
- Evaluating model performance: metrics, failure modes, and uncertainty quantification
- Best practices for optimising model deployment in real-world facility contexts
- Discussion: bridging the simulation-to-reality gap (sim-to-real transfer)
- Outlook: future directions for AI-assisted data analysis at photon and neutron facilities

## Learning Outcomes

By the end of this session, participants should be able to:

- Run inference with a trained model on new experimental or simulated data
- Critically evaluate model outputs and identify potential failure cases
- Articulate strategies for adapting simulation-trained models to real experimental conditions
