# Day 4 — Thursday 24 September (Afternoon): AI Applications — Training

## Topic

Training supervised AI models using the simulated datasets generated throughout the week.

## Content

- Overview of supervised learning workflows for scientific data
- Using realistic synthetic datasets to improve model robustness and generalisation
- Accounting for specific characteristics of experimental setups during training (instrument function, noise statistics)
- Practical session: training a model on data generated in previous sessions
- Evaluation strategies: train/validation/test splits, cross-instrument generalisation

## Learning Outcomes

By the end of this session, participants should be able to:

- Prepare a synthetic dataset pipeline feeding into a supervised training loop
- Train a basic model for a relevant task (e.g. phase identification, peak fitting, image reconstruction)
- Assess the impact of dataset realism on model performance
